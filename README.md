# ВеликіСлова (big-subtitles)

Застосунок для людей із порушеннями слуху та зору: помічник пише текст на телефоні —
і він **миттєво з'являється великим контрастним шрифтом** на екрані іншого пристрою
(напр. iPad бабусі) у реальному часі.

- **Статичний застосунок** (HTML + CSS + ванільний JS, без бандлера). Без реєстрації, без бази даних, без власного бекенду.
- Синхронізація через публічний MQTT-брокер по WebSocket (**EMQX**, `wss://broker.emqx.io:8084/mqtt`).
- Парування через **QR-код**: дисплей показує QR, помічник сканує його штатною камерою телефона.
- Дані ніде не зберігаються — текст живе лише під час сеансу.

## Як користуватися

1. Відкрийте `index.html` (через HTTPS або `http://localhost`) на **обох** пристроях.
2. На iPad натисніть **«📺 Я — Дисплей»**. З'явиться QR-код і кімната збережеться в пристрої.
3. На телефоні наведіть **камеру** на QR — браузер відкриє режим **«⌨️ Я — пишу»** у тій самій кімнаті.
4. Пишіть у полі — текст з'являється на дисплеї за < 1 с.
   - **Enter** — зсуває поточний рядок в історію на дисплеї, поле очищається.
   - **«Очистити»** — стирає поточний рядок.
5. На дисплеї в правому верхньому кутку — прихована **⚙ шестірня**: повзунок розміру шрифту,
   перемикач теми (темна/світла) і повторний показ QR.

### Щоб екран iPad не гас
Wake Lock на Safari 15 ненадійний. Увімкніть:
**Налаштування → Дисплей та яскравість → Автоблокування → Ніколи.**

## Локальний запуск і перевірка

Камера та MQTT вимагають захищеного контексту. `http://localhost` його забезпечує:

```bash
# Python
python -m http.server 8000
# або Node
npx http-server -p 8000
```

Далі відкрийте `http://localhost:8000/` у двох вкладках:

- Вкладка A: режим **Дисплей** → згенерується кімната і QR.
- Вкладка B: скопіюйте посилання з-під QR (`?role=sender#room=…`) і відкрийте у новій вкладці →
  режим **Пишу**.
- Друкуйте в B — текст має з'явитися в A майже миттєво. Перевірте Enter, перемикач теми/розміру,
  перезавантаження сторінки (кімната відновлюється), коротку втрату мережі (статус «перепідключення»).

## Приватність

Брокер **публічний** — хто знає тему кімнати, той може читати/писати. Захист — лише довгий
випадковий токен кімнати (24 символи). **Не передавайте чутливі дані.** Для приватності у
наступній версії слід перейти на власний брокер або шифрування payload.

## Структура застосунку

```
index.html              # розмітка + підключення шрифту/стилів/скриптів
css/
  styles.css            # усі стилі (теми, екрани, компоненти, анімації)
js/
  config.js             # константи: брокер, ключі localStorage, ліміти, debounce
  store.js              # безпечна обгортка над localStorage → VS.store
  utils.js              # хелпери DOM/URL, генерація токена, статус → VS.utils
  fit-text.js           # автомасштаб тексту (бінарний пошук розміру) → VS.fitText
  mqtt-client.js        # транспорт MQTT по WebSocket + протокол повідомлень → VS.mqtt
  settings.js           # тема, розмір шрифту, шестірня, банер автоблокування → VS.settings
  display.js            # режим Display: live-текст, історія, QR → VS.display
  sender.js             # режим Sender: textarea, debounce, Enter-commit → VS.sender
  app.js                # точка входу: визначає режим за ?role= → boot()
spec-velyki-slova-mvp.md # вихідна специфікація MVP
```

Усі модулі спілкуються через єдиний глобальний namespace `window.VS` і підключаються
звичайними `<script>` **у порядку залежностей** (`config → store → utils → fit-text →
mqtt-client → settings → display → sender → app`). ES-модулі навмисно не використовуються —
щоб лишитись сумісними з Safari 15 і працювати навіть із `file://`.

Шрифт — **[Andika](https://software.sil.org/andika/)** (SIL International), створений для
високої читабельності з повною підтримкою кирилиці; підключається з Google Fonts із
`display=swap` (системний sans-serif як fallback).

### Протокол повідомлень (тема `velyki/<room>`)

| Повідомлення | Коли | retain |
|---|---|---|
| `{ "type": "live", "text": "…" }` | при кожній зміні поля (debounce) | так |
| `{ "type": "commit", "text": "…" }` | натиснуто Enter — рядок іде в історію | ні |

Display тримає історію (останні ~10 рядків) у пам'яті; `retain` на `live` дає останній
рядок тому, хто приєднався пізніше.

### Як розширювати

- **Новий екран/режим** — додати секцію в `index.html`, створити `js/<name>.js` з
  `VS.<name> = { init: … }`, підключити перед `app.js` і додати гілку в `boot()`.
- **Інший транспорт** (власний брокер чи Firebase у v2) — змінити лише `js/mqtt-client.js`,
  зберігши інтерфейс `connect / encode / decode`.
- **Налаштування** — централізовано в `js/config.js`.

## Технічні нотатки

- Приймач — **iPad Air 2 / Safari 15**: код навмисно ванільний (без бандлера, без ES-модулів,
  без top-level await).
- Українська вводиться **системною клавіатурою** (Gboard / голос); Web Speech API не використовується.
- CDN: [MQTT.js](https://unpkg.com/mqtt/dist/mqtt.min.js), [qrcodejs](https://github.com/davidshimjs/qrcodejs).
