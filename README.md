# ВеликіСлова (big-subtitles)

Застосунок для людей із порушеннями слуху та зору: помічник пише текст на телефоні —
і він **миттєво з'являється великим контрастним шрифтом** на екрані іншого пристрою
(напр. iPad бабусі).

- **Статичний застосунок** (HTML + CSS + ванільний JS, без бандлера). Без реєстрації, без бази даних, без власного бекенду.
- Синхронізація через публічний MQTT-брокер по WebSocket (**EMQX**, `wss://broker.emqx.io:8084/mqtt`).
- Парування через **QR-код**: дисплей показує QR, помічник сканує його штатною камерою телефона.
- **E2E-шифрування** (AES-GCM): попри публічний брокер, текст шифрується у браузері; ключ несеться у фрагменті QR-URL і ніколи не йде на сервер.
- Текст ніде не зберігається — історія живе лише в пам'яті пристроїв під час сеансу.
- **Режими показу на дисплеї**: авто-розмір, прокрутка, суфлер і бігуча строка (з регулюванням швидкості),
  а також розмір тексту, висота рядка й тема. Помічник керує ними дистанційно.

## Як користуватися

1. Відкрийте застосунок (через HTTPS або `http://localhost`) на **обох** пристроях.
2. На iPad натисніть **«Я — Дисплей (iPad)»**. З'явиться QR-код; кімната й ключ збережуться в пристрої.
3. На телефоні наведіть **камеру** на QR — браузер відкриє режим **«Я — пишу (телефон)»** у тій самій кімнаті.
   Коли обидва пристрої на зв'язку, статус стає зеленим («з'єднано»), а QR на дисплеї ховається.
4. Пишіть у полі й натисніть **Enter** (або **«Відправити»**) — рядок з'являється великим
   текстом на дисплеї й потрапляє в історію, поле очищається. **Shift+Enter** — перенос рядка в полі.
   - **«Поле»** — стирає текст у полі без надсилання.
   - **«Дисплей»** — очищає екран і історію на дисплеї.
5. У правому верхньому куті обох екранів — **⚙ налаштування** і **📜 історія**:
   - **Дисплей:** розмір тексту, режим показу, швидкість (для суфлера/бігучки), висота рядка,
     тема, повторний показ QR. Тап по рядку історії показує його знову.
   - **Телефон:** ті самі розмір / режим / швидкість / висота рядка / тема **для дисплея**
     (надсилаються на дисплей) + власна тема телефона і показ QR. Тап по рядку історії
     повертає його в поле вводу.
6. У суфлері та бігучці можна вручну прокрутити назад — рух ставиться на паузу й
   відновлюється через 5 с бездіяльності.

### Щоб екран iPad не гас
Wake Lock на Safari 15 ненадійний. Увімкніть:
**Налаштування → Дисплей та яскравість → Автоблокування → Ніколи.**

## Локальний запуск і перевірка

Камера та Web Crypto вимагають захищеного контексту. `http://localhost` його забезпечує:

```bash
# Python
py -m http.server 8000        # або: python -m http.server 8000
# або Node
npx http-server -p 8000
```

Далі відкрийте `http://localhost:8000/` у двох вкладках:

- Вкладка A: режим **Дисплей** → згенеруються кімната, ключ і QR.
- Вкладка B: скопіюйте посилання з-під QR (`?role=sender#room=…&k=…`) і відкрийте його →
  режим **Пишу**.
- Надішліть рядок у B — він має з'явитися в A менш ніж за секунду. Перевірте історію,
  кнопки очищення, тему/розмір/висоту рядка, режими показу й швидкість, перезавантаження
  сторінки (кімната, ключ і налаштування відновлюються), коротку втрату мережі
  (статус «перепідключення…»).

## Приватність і безпека

Брокер **публічний**, тому весь текст і налаштування **E2E-шифруються** (AES-GCM, 256-біт):
хто бачить трафік, бачить лише шифротекст. **Ключ несеться лише у фрагменті URL
(`#…&k=`) — на брокер він ніколи не публікується** (фрагмент не йде у мережу).

Чесні обмеження:

- **Назва кімнати не секрет** — на публічному брокері її може побачити будь-хто.
  Секретом є тільки ключ, тобто саме QR-посилання.
- Маркери присутності («на зв'язку / ні») не шифруються.
- Немає захисту від повторного відтворення: сторонній може повторно надіслати старе
  (зашифроване) повідомлення, і дисплей покаже його ще раз. Прочитати чи підробити новий
  текст без ключа він не може.
- На брокері залишаються лише зашифровані налаштування (retained) і маркери присутності.

Не передавайте надчутливі дані: безпека сеансу = таємність QR-посилання.

## Структура застосунку

```
index.html              # розмітка трьох екранів, QR-модал, SVG-спрайт іконок, підключення стилів/скриптів
assets/                 # SVG-іконки кнопок
css/
  styles.css            # ВХІДНА ТОЧКА стилів — лише @import партіалів (дзеркало app.js)
  base.css              # дизайн-токени (CSS-змінні, у т.ч. кольори), reset, каркас екранів, утиліти
  start.css             # стартовий екран (вибір ролі)
  components.css        # спільне Display/Sender: статус, тулбар, налаштування, степер
  display.css           # Display: панель історії (спільна з Sender), live-текст, режими показу, банер
  sender.css            # Sender: поле вводу, кнопки дій
  qr-modal.css          # спільний модал парування з QR
js/
  app.js                # точка входу (type=module): визначає режим за ?role= → boot()
  config.js             # усі константи: брокер, presence, localStorage, шифрування, валідація,
                        # режими/швидкості/висота рядка, ліміти, ролі, типи повідомлень, UI-тексти
  screens/
    display.js          # режим Display: live-текст, історія, QR (init)
    sender.js           # режим Sender: поле вводу, відправка, очищення, керування налаштуваннями (init)
  components/
    settings.js         # панель Display: тема, розмір, режим, швидкість, висота рядка, банер
    live-view.js        # показ live-тексту за режимом (авто-розмір/прокрутка/суфлер/бігучка)
  utils/
    utils.js            # DOM, URL, кімната/ключ (з валідацією), статус, історія, QR-модал
    store.js            # безпечна обгортка над localStorage (get/set)
    crypto.js           # E2E-шифрування (AES-GCM): makeKeyB64/initKey/encrypt/decrypt
    fit-text.js         # автомасштаб тексту (бінарний пошук розміру)
    mqtt-client.js      # транспорт MQTT по WebSocket + протокол + presence
  vendor/               # self-host MQTT.js і qrcodejs (версії — js/vendor/README.md)
AGENTS.md               # інструкції для AI-агентів (CLAUDE.md лише посилається на нього)
spec-velyki-slova-mvp.md # вихідна специфікація MVP (історичний документ)
```

Код організовано як **ES-модулі** (`import`/`export`): `index.html` підключає лише
точку входу `<script type="module" src="js/app.js">`. ES-модулі підтримуються Safari 11+
(отже й Safari 15); top-level await не використовується. MQTT.js і qrcodejs — класичні
скрипти з `js/vendor/`, що дають глобали `mqtt` / `QRCode`.

Стилі організовано так само: `css/styles.css` — **вхідна точка**, що лише підключає
партіали через `@import`. Жодних inline-стилів у розмітці; усі власні кольори — CSS-змінні
в `base.css` (теми перемикаються атрибутом `data-theme`). Базові стилі кнопок і полів дає
[Pico CSS](https://picocss.com/).

> **Важливо:** ES-модулі **не працюють через `file://`** (CORS) — застосунок треба
> відкривати лише через `http://localhost` або HTTPS.

**Шрифти:** інтерфейс — **[Andika](https://software.sil.org/andika/)** (SIL International,
висока читабельність, повна кирилиця; Google Fonts, `display=swap`). Великий текст на
дисплеї — Arial / Helvetica.

### Протокол повідомлень

Payload — `base64url(iv).base64url(ciphertext)` (AES-GCM над JSON):

| Повідомлення | Тема | Коли | retain |
|---|---|---|---|
| `{ "type": "commit", "text": "…" }` | `velyki/<room>` | надіслано рядок — він з'являється на дисплеї й у його історії | ні |
| `{ "type": "clear" }` | `velyki/<room>` | кнопка «Дисплей» — очистити дисплей та історію | ні |
| `{ "type": "settings", "size", "displayTheme", "mode", "speed", "lineHeight" }` | `velyki/<room>/settings` | підключення Sender і кожна зміна налаштувань дисплея | так |
| `"1"` / `""` (без шифрування) | `velyki/<room>/presence/<role>` | присутність кожного пристрою; Last Will і закриття вкладки очищають | так |

`settings` йде в **окрему тему** з власним retained-слотом — тож перезавантажений Display
одразу отримує актуальні налаштування. Display підписується на обидві теми.
Display тримає останні 10 рядків історії в пам'яті.

### Як розширювати

- **Новий екран** — секція в `index.html`, `js/screens/<name>.js` з `export function init() { … }`,
  імпорт у `js/app.js` і гілка в `boot()`; стилі — окремий партіал у `css/`.
- **Інший транспорт** (власний брокер чи Firebase у v2) — змінити лише `js/utils/mqtt-client.js`,
  зберігши інтерфейс `connect / encode / decode`.
- **Налаштування** — усі «магічні» числа, рядки та значення за замовчуванням — у `js/config.js`.

Детальніше для розробників і AI-агентів — у [AGENTS.md](AGENTS.md).

## Технічні нотатки

- Приймач — **iPad Air 2 / Safari 15**: ванільний JS у вигляді ES-модулів (без бандлера,
  без top-level await). Через CORS-обмеження модулів — лише `http(s)`, не `file://`.
- Українська вводиться **системною клавіатурою** (Gboard / голос); Web Speech API не використовується.
- Бібліотеки: [MQTT.js](https://github.com/mqttjs/MQTT.js) 5.15.1 і
  [qrcodejs](https://github.com/davidshimjs/qrcodejs) — **локально** в `js/vendor/`;
  Pico CSS і шрифт Andika — з CDN.
